Política de Privacidad

Última actualización: Junio 2026

Esta Política de Privacidad describe cómo la aplicación Water Reminder recopila, usa y protege la información cuando utilizas la aplicación móvil.

Información que recopila la aplicación

La aplicación está diseñada para funcionar principalmente de manera local en el dispositivo. Los datos de hidratación, metas diarias, configuraciones y preferencias se almacenan localmente en el dispositivo del usuario.

Esto puede incluir:

  • Registros de consumo de agua
  • Metas diarias de hidratación
  • Historial y racha actual
  • Preferencias de idioma
  • Configuraciones de recordatorios
  • Cantidades rápidas configuradas por el usuario

La aplicación no requiere crear cuentas ni iniciar sesión.

Almacenamiento de datos

La información de hidratación, progreso y preferencias se almacena localmente en el dispositivo utilizando almacenamiento interno de la aplicación.

La aplicación no sincroniza datos con servidores externos ni ofrece respaldo en la nube en la versión actual.

Publicidad

La aplicación utiliza Google AdMob para mostrar anuncios. AdMob puede recopilar información como identificadores de dispositivo, dirección IP, interacciones con anuncios y datos técnicos del dispositivo para proporcionar anuncios y medir su rendimiento.

Los anuncios pueden incluir formatos como banners e intersticiales.

Reportes de errores y analítica

La aplicación utiliza Firebase Crashlytics para recopilar información técnica sobre fallos y errores de la aplicación con el fin de mejorar la estabilidad y detectar problemas técnicos.

La aplicación también puede utilizar Google Analytics for Firebase para recopilar información agregada y técnica sobre el uso de la aplicación con el fin de mejorar la experiencia del usuario y el rendimiento del producto.

Uso de la información

La información se utiliza para:

  • Permitir el funcionamiento de la aplicación
  • Guardar el progreso diario de hidratación
  • Mostrar metas, historial y racha
  • Mostrar recordatorios configurados por el usuario
  • Mejorar estabilidad y rendimiento
  • Mostrar anuncios

Compartición de datos

La aplicación no vende ni comparte información personal con terceros, excepto cuando es necesario para servicios integrados como:

  • Google AdMob
  • Firebase Crashlytics
  • Google Analytics for Firebase

Seguridad

Se toman medidas razonables para proteger la información almacenada. Sin embargo, ningún método de almacenamiento o transmisión es completamente seguro.

Cambios a esta política
